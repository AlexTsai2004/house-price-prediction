# 台北住宅房價預測

資料探勘課程期末專案（三人團隊：蔡智翔、黃子宸、黃柏碩）中，**台北住宅房價預測**部分由蔡智翔負責，
包含資料清理、特徵工程、建模與評估。本分支（`main`）是課程結束後（2026-09-25）自我檢查後的修正版本；
`final_process.py` 與 `Random_Forest.py` 直接覆蓋原版，期末繳交的原始程式保留在
[`original`](https://github.com/AlexTsai2004/house-price-prediction/tree/original) 分支。原始 EDA 報告與圖表見 `analysis/`。

## 資料

- 來源：內政部不動產實價登錄（成屋買賣 A 檔），112 年第 1 季至 114 年第 4 季，共 12 季
- 原始 57,589 筆、38 欄；移除「建築完成年月」為空者 12,732 筆（22.1%），保留 44,857 筆

## 資料下載

資料檔不放在 repo 內。來源：[內政部不動產交易實價查詢服務網](https://plvr.land.moi.gov.tw/DownloadOpenData)
→「非本期下載」，格式選 CSV，依季下載 112 年第 1 季至 114 年第 4 季。
每季只需要臺北市的 `A_lvr_land_A.csv`（不動產買賣）與 `A_lvr_land_B.csv`（預售屋買賣），
依季別放在 `taipei/` 底下（資料夾名稱須為 `年_季`，檔名大小寫須一致）：

```
taipei/
  112_1/A_lvr_land_A.csv
  112_1/A_lvr_land_B.csv
  ...
  114_4/A_lvr_land_A.csv
  114_4/A_lvr_land_B.csv
```

資料授權：政府資料開放授權條款－第 1 版。

## 執行

在 `taipei/` 目錄下依序執行：

```bash
python full_data_analyzer_with_plots.py   # 合併 12 季、篩選住家用 → 所有住家用資料_合併.csv
python impute_time_data_remove_null.py    # 時間欄位處理、移除建築完成年月空值 → 所有住家用資料_時間處理後.csv
python analyze_residential_data.py        # （選用）EDA 報告
python final_process.py                   # 特徵工程 → 所有住家用資料_特徵處理後.csv
python Random_Forest.py                   # 產生 results/metrics.json 與圖表
```

## 修正內容

| # | 問題 | 原版 | 修正版 |
|---|---|---|---|
| 1 | 資料洩漏 | 行政區 Target Encoding 在切分前以全部資料計算（原版 `final_process.py`） | 切分後只用訓練集計算（`Random_Forest.py`） |
| 2 | 誤差指標 | 「平均誤差 4.7%」為有正負號的平均，高估與低估互相抵銷 | 改報 MAPE 與中位數絕對百分比誤差；有正負號的平均標為「偏差」 |
| 3 | 相容性 | 以 `dtype == 'object'` 判斷類別欄位，新版 pandas 會漏掉 5 個類別特徵 | 明確列出類別欄位；OrdinalEncoder 只在訓練集 fit |
| 4 | 驗證方式 | 只有隨機切分 | 增加時間切分：≤113 年訓練、114 年測試 |
| 5 | 執行 | `plt.show()` 會中斷批次執行 | 圖表存至 `results/` |

模型超參數與原版相同：RandomForestRegressor，100 棵樹、max_depth 10、min_samples_split 5、min_samples_leaf 2、random_state 42。

## 結果（測試集）

| 指標 | 原版簡報 | 修正版：隨機切分 80/20 | 修正版：時間切分（114 年測試） |
|---|---|---|---|
| 訓練／測試筆數 | 35,885 / 8,972 | 35,885 / 8,972 | 39,281 / 5,576 |
| R²（log 尺度） | 0.8898 | 0.8897 | 0.8464 |
| R²（原始價格） | 0.8654 | 0.8657 | 0.7871 |
| MAPE | —（誤報為 4.7%） | 20.0% | 24.2% |
| 中位數絕對百分比誤差 | — | 13.0% | 15.9% |
| 誤差 10% 以內的比例 | — | 40.5% | 33.1% |
| 偏差（有正負號平均） | 4.7%（誤標為平均誤差） | 4.7% | 1.7% |

## 發現

1. **資料洩漏的實際影響可忽略**：只用訓練集重算後，各行政區編碼值最多相差約 0.5%，12 個行政區的相對順序不變，
   隨機切分的結果幾乎相同（R² 0.8898 → 0.8897）。但正確做法仍應在切分後計算。
2. **「平均誤差 4.7%」是錯誤的解讀**：實際平均絕對誤差為 20.0%，中位數 13.0%。
3. **時間切分下表現明顯下降**：原始價格 R² 由 0.866 降至 0.787，中位數誤差由 13.0% 升至 15.9%。
   隨機切分可能讓同期、同建案的交易同時出現在訓練與測試集，高估了預測未來成交價的能力。
4. **特徵重要度**（隨機切分）：主建物面積 0.532、交易標的 0.175、屋齡 0.101、行政區編碼 0.067。
   原專案報告寫「前三大因子為面積、地段、屋齡」，與重現結果不符。
5. **極端誤差來自非市場行情交易**：時間切分的 5,576 筆測試資料中，94 筆絕對誤差超過 100%，
   全部是模型高估（實際成交價遠低於預測）；其總價中位數 306.5 萬元，遠低於測試集整體的 1,950 萬元。
   其中 75 筆的備註含「親友」「特殊關係」「共有人」，屬親友或特殊關係間的低價交易。
   雖然模型已有「備註_親友」等特徵，仍無法反映這類交易的價格落差。
   後續可考慮將此類交易排除於訓練與評估之外，或另外建模。
