# Ames 資料

使用 Kaggle 競賽 [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
的資料。依 Kaggle 競賽規則，資料檔不放在 repo 內。

下載 `train.csv`、`test.csv` 後，放在 notebook 的同一個資料夾（`ames/`）即可執行：

```bash
kaggle competitions download -c house-prices-advanced-regression-techniques
```
